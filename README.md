# Многофункциональный Веб-Калькулятор

## Описание

Многофункциональный калькулятор на чистом **HTML + CSS + JavaScript** (без сторонних библиотек и фреймворков). Дизайн выполнен в тёмной glassmorphism-стилистике, заимствованной из проекта `flutter-lab-site`.

---

## Функциональность

| Тип | Описание |
|-----|----------|
| **Обычный** | Базовая арифметика, память (MC/MR/M+/M−/MS/MV), %, ±, 1/x, x², ²√x |
| **Инженерный** | Тригонометрия, логарифмы, факториал, степени, DEG/RAD, научная нотация |
| **Программист** | HEX/DEC/OCT/BIN, побитовые операции, сдвиги, BYTE/WORD/DWORD/QWORD |
| **Вычисление даты** | Разница между датами / добавить-вычесть дни |
| **Валюта** | Конвертер на основе API ЦБ РФ, кеш 1 час |
| **Объём** | 12 единиц (мл, л, галлон, кварта и др.) |
| **Длина** | 11 единиц (мм, см, м, км, дюйм, миля и др.) |
| **Матрицы** | det, транспонирование, обратная, ранг; A+B, A−B, A×B, AX=B; до 6×6 |
| **Биквадратное** | ax⁴+bx²+c=0; все вещественные и комплексные корни; авто-упрощение при a=0 |
| **Система 2×2** | Ax+By+C=0 / Dx+Ey+F=0; правило Крамера; обработка вырожденных случаев |

---

## История операций

- Хранится в `localStorage` (до 50 записей)
- Записывается для: Обычный, Инженерный, Программист
- **Desktop:** всегда видна в правой панели
- **Mobile:** выезжает справа по кнопке истории (🕐)

Открыть `index.html` в браузере — никаких зависимостей, сборки или сервера не требуется.

## Технологии

- **HTML5** — семантическая разметка, `data-*` атрибуты
- **CSS3** — CSS-переменные, Grid, Flexbox, `backdrop-filter`, `@media`, анимации
- **JavaScript (ES6+)** — классы, `async/await`, `fetch`, `localStorage`, CustomEvent
- **API ЦБ РФ** — `cbr-xml-daily.ru/daily_json.js` — бесплатный российский курс валют

## Клавиатурное управление

Работает для **Обычного** и **Инженерного** калькулятора:

| Клавиша | Действие |
|---------|----------|
| `0`–`9` | Ввод цифры |
| `+` `-` `*` `/` | Арифметические операции |
| `Enter` или `=` | Вычислить результат |
| `Backspace` | Удалить последний символ |
| `Delete` / `Escape` | Полный сброс (C) |
| `.` или `,` | Десятичная запятая |
| `%` | Процент |
