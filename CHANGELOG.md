## [1.0.0] — 2026-05-31

### Добавлено

#### Структура проекта
- `index.html` — разметка всего приложения: шапка, боковые панели, 7 секций калькулятора
- `style.css` — полная система стилей в тёмной теме glassmorphism
- `script.js` — логика всех калькуляторов, менеджер истории, контроллер UI

#### Дизайн-система
- Цветовые переменные, типографика и стилистика перенесены из проекта `flutter-lab-site` (шрифты Trebuchet MS / Segoe UI, акцент-цвет `#50c8ff`, тёмный фон `#080a11`, стекломорфизм)
- Логотип проекта используется в шапке и в боковом меню
- Плавные переходы и анимация появления панелей (`fadeIn`, `transform: translateX`)

#### Макет и навигация
- **Desktop (≥ 900px)**: три колонки — левый сайдбар (240px), основная область, правая панель истории (260px)
- **Mobile (< 900px)**: одна колонка; сайдбар и история вызываются через кнопки в шапке, выезжают как overlay с затемнённым фоном
- Кнопка гамбургер-меню (`≡`) открывает/закрывает сайдбар на мобильных
- Кнопка истории (иконка часов) открывает/закрывает панель истории на мобильных
- Клик по overlay-фону закрывает открытые панели

#### Обычный калькулятор
- Стандартные арифметические операции: +, −, ×, ÷
- Специальные функции: %, ±, 1/x, x², ²√x
- Очистка: CE (сбросить ввод), C (полный сброс), ⌫ (backspace)
- Шесть ячеек памяти: MC, MR, M+, M−, MS, MV
- Отображение текущего выражения (верхняя строка) и результата (нижняя крупная строка)
- Сохранение вычислений в историю

#### Инженерный калькулятор
- Наследует весь функционал обычного калькулятора
- Переключатель режима углов **DEG / RAD**
- Переключатель научной нотации **F-E** (`toExponential`)
- Кнопка **2nd** (визуальный переключатель, расширяемый функционал)
- Константы: **π** (`Math.PI`) и **e** (`Math.E`)
- Функции: **exp** (e^x), **|x|** (модуль), **mod**, **xʸ** (возведение в степень), **10ˣ**, **log** (log₁₀), **ln** (натуральный логарифм), **n!** (факториал до 170)
- Выпадающий список **«Тригонометрия»**: sin, cos, tan, cot, sin⁻¹, cos⁻¹, tan⁻¹, cot⁻¹, sinh, cosh, tanh
- Выпадающий список **«Функция»**: log, ln, ²√x, ³√x, n!, Rand (случайное число 0–1)
- Сохранение вычислений в историю

#### Программист-калькулятор
- Четыре строки дисплея с одновременным отображением значения в **HEX, DEC, OCT, BIN**
- Переключение активной системы счисления кликом по строке (автоматическое преобразование)
- Ограничение вводимых символов по выбранной системе
- Типы слова: **BYTE** (8 бит), **WORD** (16 бит), **DWORD** (32 бит), **QWORD**
- Побитовые операции через выпадающий список: **AND, OR, NOT, XOR, NAND, NOR**
- Операции сдвига через выпадающий список: **LSH (<<), RSH (>>)**
- Базовая арифметика (целочисленная): +, −, ×, ÷, %
- Кнопки HEX-цифр A–F (неактивные при OCT/BIN/DEC)
- Мини-память: MS, MV
- Сохранение вычислений в историю

#### Вычисление даты
- Режим «**Разница между датами**»: два поля-датапикера, результат в годах/месяцах/днях с учётом русских склонений
- Режим «**Добавить / вычесть дни**»: один датапикер, ввод количества дней, кнопки «Добавить» / «Вычесть», результат — конкретная дата

#### Валюта
- Интеграция с **API ЦБ РФ** (`cbr-xml-daily.ru/daily_json.js`) — российский сервис, работает в РФ, бесплатно
- Загрузка актуальных курсов при старте; кеширование в `localStorage` на 1 час
- Кнопка «Обновить курсы» для принудительной загрузки
- Двусторонняя конвертация: ввод в любом из полей пересчитывает второе
- Отображение информационной строки: «1 USD = 82.5 RUB · Обновлено: 2026-05-31»
- Офлайн-фолбэк с базовыми курсами при отсутствии сети
- Русские названия основных валют: RUB, USD, EUR, GBP, CNY, JPY и других

#### Объём (конвертер)
- 12 единиц: мл, л, м³, чайная ложка (США), столовая ложка, жидкая унция, чашка, пинта, кварта, галлон, куб.дюйм, куб.фут
- Двусторонняя конвертация в реальном времени при вводе

#### Длина (конвертер)
- 11 единиц: нм, мкм, мм, см, м, км, дюйм, фут, ярд, миля, морская миля
- Двусторонняя конвертация в реальном времени при вводе

#### История операций
- Сохранение в `localStorage` (ключ `calc_history`), максимум 50 записей
- Запись содержит: тип калькулятора, выражение, результат, временну́ю метку
- История ведётся только для вычислительных типов: Обычный, Инженерный, Программист
- Desktop: история всегда видна в правой панели
- Mobile: история доступна через кнопку в шапке
- Кнопка «Очистить историю» с мгновенным обновлением отображения

#### Клавиатурная поддержка
- Для Обычного и Инженерного калькулятора: цифры 0–9, операторы + − * /, Enter или = для вычисления, Backspace, Delete/Escape для сброса, `.` или `,` для десятичной точки, `%` для процента
- Ввод с клавиатуры игнорируется, если фокус на поле ввода (input/select)

## [1.1.0] — 2026-06-01

### Добавлено

#### Калькулятор матриц
- Новый тип в боковом меню: **Матрицы** (значок ⊠)
- Поддержка матриц от **1×1 до 6×6** с настройкой размера через выпадающие списки
- Переключатель режимов: **только матрица A** / **матрицы A и B**
- **Операции над одной матрицей (A):**
  - Определитель `det(A)` — рекурсивное разложение по первой строке
  - Транспонирование `Aᵀ`
  - Обратная матрица `A⁻¹` — метод Гаусса–Жордана на расширенной матрице `[A|I]`
  - Ранг `rank(A)` — ступенчатый вид методом Гаусса
- **Операции над двумя матрицами (A и B):**
  - Сложение `A + B`
  - Вычитание `A − B`
  - Умножение `A × B`
  - Решение системы `AX = B` — метод Гаусса–Жордана
- Результат отображается ниже матриц: скаляр крупным шрифтом, матрица — в виде таблицы ячеек
- Форматирование чисел: целые без дробной части, остальные до 4 знаков после запятой
- Обработка ошибок: несовместимые размеры, вырожденная матрица, отсутствие единственного решения

## [1.0.1] — 2026-06-01

### Исправлено

- **Overlay/sidebar z-index (мобилка):** убран `position: relative; z-index: 1` с `.app-layout`, который создавал stacking context и прижимал дочерние fixed-панели (sidebar, history) ниже overlay по уровню отрисовки. Теперь sidebar и history корректно отображаются поверх затемнения.
- **Кнопка %:** при нажатии без предыдущей операции (например, 50 %) теперь корректно возвращает 0.5 (вместо исходного значения). При наличии операции поведение не изменилось: 50 + 20% показывает 10, затем = даёт 60.
- **Кнопка = в обычном калькуляторе:** убран класс `btn-wide` (span 2) с кнопки 0, чтобы последний ряд +/− · 0 · , · = ровно заполнял 4 колонки и не переносил = на новую строку.
